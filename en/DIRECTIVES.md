# DIRECTIVES — the agent's behavior

> Read at every startup (`AGENTS.md` §1.4, **Active** section) and applied for the whole session. It is the only file that really changes the agent's behavior from one session to the next.
> **Automatic learning**: what the loop deduces (`protocols/learning.md`) and what the user asks for explicitly (fast track) becomes active **without waiting for a « yes »**, in §Learned (automatic), marked `[auto YYYY-MM-DD — not announced]`; it is announced to the user, then marked `announced`. They say it bothers them → removed at once (`_archive/`), never proposed again.
> Each entry carries a **Basis**: concrete evidence (session/date, short quote), 2-3 lines max. A reconfirmation updates a counter and the most recent date, it does not lengthen the text.
